About this page

Purpose. One place to see whether each PMLB work tool on GitHub Pages is serving the latest version.

How it works. The latest versions come from versions.json beside this page, which Claude updates on every release. The live version is read from each tool page's tool-version tag; tools without the tag fall back to the version in their title. Personal tools are not listed.

History of a tool. "History" opens the commit list for that tool's index.html; every version ever published can be viewed or downloaded there. "Changelog" opens the repo's CHANGELOG.md.

Version history. v1 — 17 Nov 2026 — first version (pilot).
